# 系统框图与立项说明

> 立项日期：2026-10-21（W1 第一天）

## 一句话定义

基于 STM32F103 + FreeRTOS 的多通道数据采集节点：两路传感器数据经队列解耦、协议打包后由 UART 上传，Python 上位机负责解析、校验、存储与实时可视化。

## 数据流框图

```
┌─────────────┐        ┌──────────────────────────────┐        ┌──────────────────┐
│ 模拟量输入    │ ADC+DMA │                              │        │  PC 上位机         │
│ 电位器        │───────▶│  采集任务                      │ UART帧  │  pyserial 接收     │
└─────────────┘        │      │                         │───────▶│  状态机解析 + CRC   │
┌─────────────┐        │      ▼                         │ USB-TTL│  CSV 落盘          │
│ I2C 传感器   │───────▶│  队列 Queue（生产者→消费者）      │        │  实时曲线           │
│ MPU6050 六轴   │        │      │                         │        │  丢帧率统计         │
└─────────────┘        │      ▼                         │        └──────────────────┘
                       │  发送任务（按协议打包）             │
                       │  STM32F103 · FreeRTOS            │
                       └──────────────────────────────┘
```

## 模块职责

| 模块 | 职责 | 对应周 |
|---|---|---|
| 采集任务 | ADC(DMA) + I2C 驱动，生产数据 | W2 |
| 队列 Queue | 任务间解耦，削峰 | W2 |
| 发送任务 | 帧头+长度+通道+数据+CRC 打包上传 | W2 |
| 上位机 | 状态机解析、CSV、实时曲线、丢帧统计 | W3–W4 |

## 验收标准

**连续运行 2 小时零丢帧**（上位机序号断号统计为准）。
